# Radio Velvet for Alexa

Live radio by voice, Malayalam first: "Alexa, open Radio Velvet", "Alexa, ask Radio Velvet to play Radio Mango",
"… to play Malayalam radio", "… to play the Velvet Selection", then "next", "previous", "pause", "resume", "what's playing".

This repository is the Alexa skill as Amazon imports it (`skill-package/` and `lambda/`). The working copy, tests and the
job that keeps the station list fresh live in the website repository (`alexa/` there); this copy is refreshed from it.
Stations: https://ranjithkb.com/js/alexa-stations.json (read every hour). Privacy: https://ranjithkb.com/privacy.html#alexa
